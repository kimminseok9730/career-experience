# 꿈을 찾아! 드림 — 직업 체험

웹 브라우저에서 바로 해 보는 직업 체험 앱입니다. 설치 없이 아래 주소로 열 수 있습니다.

**https://kimminseok9730.github.io/career-experience/**

## 들어 있는 체험

- **직업 둘러보기** — 직업 소개와 하는 일
- **전기안전관리자** — 중계펌프장 3D 현장을 돌며 계기와 설비를 관찰하고 기록하는 체험 (`experience.html`)
- **법의관 · CASE 01** — 사건 접수(`case.html`) → 걸어 다니는 부검실과 심장 관찰(`forensic.html`) → 전문감정 의뢰(`consult.html`)

## 알아 둘 것

- 모든 사건은 **교육용 가상 사례**입니다. 실제 인물·사건이 아닙니다.
- 법의관 체험의 심장은 Human Reference Atlas(Visible Human Male) 자료의 심장 하나를 잘라 만든 교육용 모형입니다. 지방·혈관 굵기·조직의 색과 형태는 교육용으로 재구성했으며 **의학 감수를 받지 않았습니다.** 실제 부검·진단을 훈련하는 자료가 아닙니다.
- 관찰 기록은 이 브라우저(localStorage)에만 저장됩니다. 서버로 보내지 않습니다.
- 3D 화면은 그래픽 성능이 낮은 기기에서 느릴 수 있습니다. 법의관 화면은 처음에 약 30MB를 내려받습니다.
